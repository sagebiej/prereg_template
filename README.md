# Pre-Registration Template for Choice Experiments

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.14993224.svg)](https://doi.org/10.5281/zenodo.14993224)

A customized pre-registration template specifically designed for discrete choice experiments (DCEs). This template accompanies the paper *"A Pre-Registration Template for Transparent Choice Experiment Research"* .


## Versioning

This template is versioned. The current version and release date are displayed in the template itself (title page and footer). Versions are tracked on Zenodo:

> **DOI: [10.5281/zenodo.14993224](https://doi.org/10.5281/zenodo.14993224)**

When citing this template, please use the DOI above to ensure reproducibility and to link to the exact version used in your study.

---

## How to Use

1. **Download** the template in your preferred format from [Zenodo](https://doi.org/10.5281/zenodo.14993224) or clone this repository.
2. **Fill in** each section before data collection begins.
3. **Upload** the completed pre-registration to a time-stamped platform such as [OSF](https://osf.io), [AsPredicted](https://aspredicted.org), or the [AEA RCT Registry](https://www.socialscienceregistry.org).
4. **Attach** supplementary materials (questionnaire, design code, simulation results) using the Resources section in Part D.

## Contributing

This template is a living document. As methods in discrete choice analysis evolve, the template should evolve too. Contributions are welcome:

- **Bug reports and suggestions**: Open an [issue](https://github.com/sagebiej/prereg_template/issues).
- **Proposed changes**: Submit a [pull request](https://github.com/sagebiej/prereg_template/pulls).

The research community is invited to contribute updates as new design strategies, estimation methods, or validity measures emerge.
